# TroutBox

Интерактивный прототип мобильного приложения для учёта приманок и истории уловов.

**Открыть:** https://mymediim.github.io/troutbox-prototype/

Моя коробка, каталог, желания, частичные потери и восстановление, история уловов, светлая и тёмная темы. Без регистрации и заказов. Данные и загруженные фотографии хранятся только в браузере посетителя.

Модели, характеристики и изображения демонстрационные. Изображения — векторные иллюстрации, не фотографии товаров. Шрифт Manrope — SIL Open Font License.

Статический сайт: HTML, CSS и JavaScript, без серверной части и внешних API. Для локального просмотра используйте HTTP-сервер. GitHub Pages публикуется из корня ветки main.
