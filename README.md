# TroutBox

Интерактивный прототип мобильного приложения для учёта приманок и истории уловов.

**Открыть:** https://mymediim.github.io/troutbox-prototype/

Главная, отдельная коробка с ячейками, каталог, желания, частичные потери и восстановление, дневник уловов со стикерами рыб, рекордами, местом ловли и выбранной приманкой. Светлая и тёмная темы. Без регистрации и заказов. Данные и загруженные фотографии хранятся только в браузере посетителя.

20 моделей с фотографиями и характеристиками из [форелевого каталога VobleryTop.ru](https://voblerytop.ru/fish/trout/). Дата проверки: 21 октября 2026. Источник указан в каждой карточке. Основное фото может показывать серию, характеристики соответствуют выбранному размеру. Стартовый набор и уловы демонстрационные. Старые записи поддерживаются без переименования приманок. Шрифт Manrope — SIL Open Font License.

Статический сайт: HTML, CSS и JavaScript, без серверной части и внешних API. Для локального просмотра используйте HTTP-сервер. GitHub Pages публикуется из корня ветки main.
